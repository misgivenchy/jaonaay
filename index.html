เปิดหน้าค้นหาเวร (Public)

ระบบจัดตารางเวรกองรักษาการ ระบบสุ่มเวรเฉลี่ยเท่ากัน

หน้าสำหรับคนทั่วไป (Public)

ตรวจสอบและมอบหมายสายงานกำลังพลประจำหมวด

เลือกหมวดที่จะจัดเข้าเวร (ต้องเลือกอย่างน้อย 2 หมวด) และเปลี่ยนหน้าที่/สายงานของทหารแต่ละนายได้ทันทีก่อนกดสร้างตาราง
เลือกหมวดเข้าเวร *(เลือกอย่างน้อย 2 หมวด):
💡 คำแนะนำ: คนที่อยู่ "พัฒนากองร้อย" จะอยู่กลุ่มบนเข้าเวรวันปกติ ส่วนคน "นอกพัฒนากองร้อย" จะอยู่กลุ่มล่างเข้าเฉพาะวันเสาร์
ลำดับ หมวด ชื่อ - สกุล ผลัด หน้าที่ / สายงาน ประเภทเวรที่เข้า พื้นที่ (นครสวรรค์/อีสาน) สถานะเวร ตำแหน่งจัดเวรในตารางอัตโนมัติ นำออก
🛡️ กำลังพลหลัก (พัฒนากองร้อย): 0 นาย
🛡️ วันเสาร์ (นอกกองร้อย): 0 นาย
🎖️ ผช.สิบเวร: 0 นาย
🍳 ยกเว้นเวร (สื่อสาร/บก.ร้อย/บ้านผบ./โรงเลี้ยง): 0 นาย
🚫 นำออกชั่วคราว: 0 นาย

💡 เคล็ดลับ: สามารถคลิกที่ช่องตัวเลขในตารางเพื่อแก้ไขเลข 0-4 หรือคลิกช่อง ผช.สิบเวร เพื่อเปิด/ปิดแถบสีเขียวได้โดยตรง
กดปุ่มนี้เพื่อยืนยันส่งตารางไปยังหน้าสำหรับบุคคลทั่วไป (ภาพที่ 3) พร้อมรับลิงก์สำหรับส่งต่อในกลุ่ม LINE และ QR Code สำหรับเปิดดูในโทรศัพท์
